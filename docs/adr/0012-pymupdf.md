# ADR-0012 · PyMuPDF para PDF
Estado: Aceptado (por decisión de uso) · 05-11-2026
**Contexto:** PyMuPDF es AGPL-3.0 o comercial [V]. Mejor extracción de trazados vectoriales.
**Decisión:** se usa, porque el programa es de uso estrictamente personal y no se distribuye
(respuesta del usuario 05-11-2026).
**Revisar si:** el programa llega a instalarse en otros equipos; alternativas permisivas:
pypdfium2, pdfplumber.
