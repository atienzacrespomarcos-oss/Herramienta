# ADR-0011 · Open CASCADE aplazado
Estado: Propuesto · 05-11-2026
**Decisión:** interferencias con primitivas simples (cajas orientadas, cilindros) y Shapely
en 2D. OCCT (LGPL-2.1 + excepción [V]) solo si IFC o la geometría lo exigen.
Con estructura limitada a geometría, la necesidad de OCCT es menor.
