# ADR-0007 · Normativa como datos citados
Estado: Propuesto · 05-11-2026
**Decisión:** ningún umbral normativo en el código; todos en `data/normativa/*.yaml` con
fuente, nivel y verificación. El proyecto fija las versiones con las que se calculó.
**Sin UNE:** las fuentes públicas que reproducen una UNE son nivel 3 (`fuente_secundaria`),
contrastadas y con discrepancias visibles (ver `ENGINEERING_METHODOLOGY.md`).
